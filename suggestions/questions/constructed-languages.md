# Name an invented language.

Question id: `constructed-languages` · category: language · source: `data/language.json`

Rules: Any language made up on purpose: for the world, for fiction or as an experiment. Language games like Pig Latin, programming languages and codes don't count.

The game already forgives capitals, accents, punctuation, a leading "the", simple plurals, "St" for "Saint", number words, a title in front (King, Sir, Dr and the like), the question's own words at the end ("Cheddar cheese"), a year at the end, and small typos (one wrong letter in a short name, more in a long one), so there is no need to suggest those variants.
